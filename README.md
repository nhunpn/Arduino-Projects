# Arduino-Projects

These are some of my Arduino projects using Arduino Uno R4 Wifi showcasing 

## Projects

### 1. Light Box
An interactive shadow light box that combines motion detection, ambient light sensing, and LED/LCD display for a functional and artistic light box.
How it works:
- Uses a PIR motion sensor to detect hand movement and turn on the light.
- Uses a light sensor to measure ambient brightness and adjust LED intensity automatically.
- Displays messages on the LED and LCD boards.
Demo: https://drive.google.com/file/d/1siGeudyGbWeCO51EwXXLt_1TpvfzxOiA/view?usp=sharing

### 2. Interactive Logic Gates
An interactive Arduino-based logic gates device designed to help students who are blind or have low vision learn basic digital logic concepts.
How it works: 
- Uses push buttons to simulate inputs for the logic gates.
- Uses a slide switch to turn the device on and off.
- Outputs results with unique buzzer sounds and displays outputs on the LCD for instructors.
Demo: https://drive.google.com/file/d/12LpcJO06XBEFk4V3sGFE8CVYsvyhk6BV/view?usp=sharing
